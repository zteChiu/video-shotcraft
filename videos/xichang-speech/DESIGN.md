# 西厂 · 这就是西厂

39 秒、1920×1080、30fps。画面只做一件事：把这段人声写成一张能读完的判词。没有产品界面，也没有配乐——声音就是这段录音。

## 录音与字幕

时长 37.43 秒。上传的 srt 是识别稿，同音错字按录音改过，时间码不动：

| 识别稿 | 画面 |
|---|---|
| 江湖建设 / 卑躬摄影 | 江湖剑客 / 杯弓蛇影 |
| 所在庙里探戚 | 缩在庙里叹气 |
| 西场 / 东场 | 西厂 / 东厂 |
| 摆破 / 先掌后奏 | 来破 / 先斩后奏 |
| 东厂破不了到我更要管 | 东厂破不了的，我更要管 |

最后一句保留「破不了」，不改成电影台词里的「管不了」。识别结果是破，不是管。

## 方向

朱砂夜殿。漆黑底、骨色宋体、金是皇权、朱砂是刀。能量从冷（讥讽）到砸（算什么东西）到收（你问我）再到宣言堆叠，最后一印落在「这就是西厂」。

动效只借两张卡的手感，不借它们的产品画面：

- `paper-title-card` 的压印：scale 1.22→1，blur 7→0，bezier(0.2, 0.75, 0.3, 1)
- `score-slam` 的落点：7 帧 ease-in 砸到 0.965，再 12 帧回到 1

全片整画面冲击只有两下：7.4 秒「西厂算什么东西」，34.0 秒印落。其余句子只动字本身。

## 镜头

| 镜头 | 时间 | 画面 |
|---|---|---|
| 杯弓蛇影 | 0–7.4s | 左对齐三句，金线作轴，杯弓蛇影用金，替皇上分忧用朱砂 |
| 算什么东西 | 7.4–15.4s | 主句砸下；三句跟在下面。14.8–15.4s 人声换气，字退回空殿 |
| 你问我 | 15.4–19.8s | 同一句换回金色「西厂」，慢压印，不再砸 |
| 东厂西厂 | 19.8–31.6s | 六句左齐排成一份判词，「一句话」用朱砂断开 |
| 这就是西厂 | 31.6–39.0s | 先斩后奏让位，印与句一起落下，够不够清楚停到片尾 |

字号都在 60px 以上。成片尾多留约 1.6 秒，让最后一句在人声结束后还站着。

## 声音

只用人声，音量 1。不铺 BGM，不加音效。鼓点和 whoosh 会盖过这句话。

## 渲染

人声文件不进 git。放到 `public/audio/voice.mp3` 再渲染：

```bash
cd videos/xichang-speech
npm install
npx remotion render src/index.ts XichangSpeech out/xichang.mp4 --concurrency=2
```

无显示器的 Linux 上加 `--browser-executable` 指向本机 Chrome。字体是 Noto Serif SC 切出的 Medium / Bold，只收本片用字，OFL 见 `public/fonts/OFL.txt`。工作台里改成这套字以外的字会缺字。
