# Ferrari — Bebe Rexha

一首 3 分 33 秒的歌词片。画面是穆赫兰夜路的一次靠边：左边是暗的山脊，右边是城里的灯。歌词锁在提供的 LRC 演唱时间上，路的速度跟着段落走，不跟着每一拍抖。

## 为什么不是产品片模板

这不是页面宣传片。镜头卡里的产品运镜用不上。文字运动借用 blur-slide 的做法：位移、模糊、透明度走同一条 ease-out，词和词错开，中文在英文还没落完时就跟上。开场字标单独给一条 3 秒的进入，然后停住。

副歌里两句中文的原 LRC 是把一整句拆开、时间戳和英文对不齐（「我就像在穆赫兰大道上」配在 “I'm a Ferrari” 下面）。成片按意思把现成的译句对回正在唱的英文，没有新写翻译。

## 节奏

低音能量的网格大约是 153 BPM。演唱不量化到网格上，否则会和人声错开。三次地平线光晕落在测到的最强瞬态上，彼此隔得很开：

- 76.90s，第一段 whoa 之前
- 155.34s，第二段 whoa 之前
- 178.86s，最后一遍副歌进来之前

整画面没有缩放泵，也没有震屏。速度只作用在路的虚线和窗灯的拉线上。

## 速度

主歌巡航，pre-chorus 把车刹下来，每一遍副歌再加速，最后一句 “kinda lonely” 把车停住。中文在 207.06s 才出现，车已经停了。

## 渲染

把音频放到 `public/audio/ferrari.mp3`，然后：

```bash
cd videos/ferrari
npm install
npm run render
```

成片 `out/ferrari.mp4`，1920×1080，30fps。
